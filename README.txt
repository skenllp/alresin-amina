Alresin & Amina — wedding invitation (HTML + CSS + vanilla JS)

Live site: https://alresin-amina.vercel.app/
Open Graph image: assets/wedding-og.jpg (1200x630), referenced as https://alresin-amina.vercel.app/assets/wedding-og.jpg
After redeploying, refresh WhatsApp's cached preview at https://developers.facebook.com/tools/debug/ (or share the link with ?v=2 appended).

Run locally:  python3 -m http.server 8000   then open http://localhost:8000
Deploy: upload the whole folder (index.html, style.css, script.js, assets/).

Music: assets/wedding-music.mp3 plays only after the guest taps "Open Invitation" (loops at ~35% volume). The round button at the bottom-right mutes/unmutes the music later.
